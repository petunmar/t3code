# File attachments

On web and desktop, drag files onto the message composer or paste files from the clipboard. The files appear above the input and are sent with your next message.

Images are delivered as visual input when the selected provider supports vision. PDFs and other files are uploaded to the T3 environment and made available to the agent as local files, including when you are connected remotely.

Each message can include up to 8 attachments. Each attachment can be up to 10 MB. Files that cannot be stored in the browser draft are marked and should be sent before navigating away.
